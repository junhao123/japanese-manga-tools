# 日本語の吹き出し・漫画制作ツールまとめ

画像や漫画に「吹き出し（セリフ枠）」を入れるためのツールを、
**縦書き対応 / 商用利用 / 登録要否 / 透過PNG保存** の4点で比較した一覧です。

最終更新: 2026-11-21

| ツール | 縦書き | 商用利用 | 登録 | 透過PNG | 特徴 |
|---|---|---|---|---|---|
| [吹き出しメーカー](https://fukidashimaker.com/?utm_source=github&utm_medium=referral) ※運営 | ○ | ○ | 不要 | ○ | 6形状・しっぽ8方向・回数制限なし・画像はアップロードされない |
| Canva | － | 条件付き | 必要 | ○ | 総合デザイン、テンプレートが豊富 |
| Photopea | ○ | ○ | 不要 | ○ | 画像編集全般、多機能だが操作は複雑 |
| AddSpeechBubble | × | 有料版のみ | 不要 | ○ | 形状の種類が多い |
| フキダス | ○ | － | 不要 | － | 縦書き対応、シンプル |
| Speech Bubble Meme | × | － | 不要 | ○ | ミーム画像向け |
| CreateComic | － | － | 必要 | ○ | コマ割りまで作れる |
| ibisPaint | ○ | 条件付き | 不要 | ○ | スマホのお絵かきアプリ |
| MediBang Paint | ○ | ○ | 不要 | ○ | 漫画制作向け、無料 |
| ちびむすドリル（素材） | － | － | 不要 | － | 印刷向けの無料素材 |

## 選び方

- **縦書きの日本語セリフを入れたい** → 吹き出しメーカー、フキダス、Photopea
- **登録もインストールもせず、すぐ画像に足したい** → 吹き出しメーカー、フキダス
- **商用・グッズ販売に使いたい** → 吹き出しメーカー（出力画像は自由に使えます）
- **コマ割りから作りたい** → CreateComic、MediBang Paint

※「－」は未確認、「×」は非対応です。仕様は各ツールでご確認ください。
